Who's Accepting Doctoral Students

Clinical psychology runs on the mentor model — if your person isn't taking a student, the application usually can't go anywhere. This tracks who's accepting for the coming cycle, alongside what each program actually asks for: the application deadline, whether the GRE is required, how many letters of recommendation you'll need, and anything else worth knowing before you apply.

298 faculty confirmed accepting across 59 programs · last updated 2026-08-31

Every name here was read from the program's own page on the date shown, and the sentence it came from is quoted so you can judge it yourself. We never take faculty names from search results — when we tested that, search under-reported UCLA as 3 faculty when the real page listed 7, and FIU as 6 when the page listed 11.

This directory is being built and is nowhere near complete. There are roughly 250 APA-accredited clinical doctoral programs; only the ones below have been checked. A program not listed here means we haven't got to it — not that nobody is accepting. Most programs post their lists between August and October, so check back. Always confirm on the program's own page before you apply.
