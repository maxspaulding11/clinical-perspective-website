APA Citation Generator

Paste a DOI, PubMed ID or ISBN. You'll get a correctly formatted APA 7 reference, both in-text citation forms, and a Word reference page ready to hand in.

Add a source

One per line to add several at once. Look-ups come from CrossRef, PubMed and Open Library — the same records the publishers file themselves.

APA wants article and book titles in sentence case. Acronyms, place names and organisations are preserved automatically — but a personal surname inside a title (“…a reply to Smith”) can't be told apart from an ordinary word, so give those a glance and use Edit to fix.

No DOI? Enter a source by hand — web pages, books, chapters, reports, theses

Your reference list

Alphabetised automatically, with hanging indents.

    Your references are saved in this browser only — nothing is uploaded, and there's no account. Clearing your browsing data will clear the list, so download the Word file when you're done. Citation data comes from CrossRef, PubMed and Open Library; records are occasionally incomplete, so give each reference a quick check before you submit it.
